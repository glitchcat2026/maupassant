# my-maupassant

This is an edited maupasspant typecho template. Original link is [here](https://github.com/pagecho/maupassant/).

This is added following features:

- Support darkmode
- Support Latex Rendering
- Support topbar second-level menu
- Noto Sans SC is now the only font
- Removed support for IE
- Tables will be three-line tables
- If Plugin [ViewsCounter](https://github.com/Quarkay/Typecho-ViewsCounter) is installed, counts will be displayed
